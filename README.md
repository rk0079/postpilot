# PostPilot — Instagram scheduler

Standalone front-end dashboard for planning Instagram photos, carousels, videos, and reels.

## Run it

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Included interactions

- Weekly content calendar with queue health and best-time insights
- Single content scheduling for carousel, photo, reel, and video posts
- Bulk schedule mode with mixed-media upload/drop zone and batch preview
- Content library, quick actions, workspace navigation, notification, and toast states
- Responsive layout for desktop, tablet, and mobile widths
